# Runtime evidence checklist

This directory is intentionally not populated with fabricated screenshots. After deployment in your own Camunda 8 SaaS cluster, save genuine screenshots here:

1. Web Modeler BPMN diagram and DMN table.
2. Linked manual-review form.
3. Operate: approved and rejected instances.
4. Tasklist: manual review task before and after completion.
5. Operate: worker failure incident, corrected variable, retry result.
6. Operate: REST Connector HTTP 503 incident, corrected variable, retry result.
7. Terminal output showing the Spring Boot worker and API.
